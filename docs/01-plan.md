## 2. 这个网站到底能干什么

### 看（建立"这牌子有东西"的感觉）
- 首页五个章节，像翻一本杂志，往下滚，下一页盖住上一页
- 工艺故事：泥怎么变成器，配图配短句，不写大段说明文
- 每件陶器有自己的系列、釉色、尺寸、工艺说明

### 买（完整链路，缺一不可）
- 逛 → 筛（器型/系列/釉色/价格/能否定做）→ 详情 → 收藏 / 加购物袋
- 购物袋 → 填地址 → 结算 → 支付（第一版模拟）→ 订单记录 → 确认收货
- 订单状态：待支付 → 已支付/待发货 → 已发货 → 已完成，可取消

### 玩（这块是差异点）
- **自己定做**：选器型（杯/碗/花器）→ 选纹样 → 选颜色 → 调位置大小 → 实时预览 → 存方案 / 直接下单
- **纹样库**：每个纹样有名字、来源、寓意、适合哪些器型；能筛、能看详情、能"拿去做定做"
- **垚垚**：右下角一直在，点开能聊；页面换了场景她会换动作

### 我的
订单 / 收藏 / 我的定做 / 收货地址 / 账户设置

## 3. 导航怎么规划（重点）

原则：**客户一眼知道点哪里**。所以一级导航只用五个大白话词，不用"器物志""匠造"这类词。

| 一级入口 | 点进去是什么 |
|---|---|
| **逛陶器** | 所有在售的陶器，能筛能排 |
| **自己定做** | 选器型、纹样、颜色，做出自己的一件 |
| **纹样库** | 有哪些花纹、每个花纹什么来头 |
| **工艺故事** | 泥怎么变成器，人和工作室 |
| **我的** | 订单、收藏、定做、地址 |

右侧固定三件套：**搜索**、**收藏**、**购物袋（带数量）**；再往右下是**垚垚**。

### 三种导航形态，按页面分工

| 页面 | 用什么导航 | 为什么 |
|---|---|---|
| 首页 | **右侧竖排章节条**（01 封面 / 02 这一期 / 03 从泥到器 / 04 留下一道纹样 / 05 认识垚垚），滚动时高亮当前章 | 首页是长滚动，横排菜单会打断杂志感；竖排编号像目录 |
| 商品列表 | **左侧筛选栏**（可收起）+ 顶部横排导航 | 筛选要一直在手边，客户边看边改条件 |
| 其他内页（详情、定做、购物袋、结算、我的…） | **顶部细横条**：左边品牌名，中间五个入口，右边搜索/收藏/购物袋 | 清楚、不抢戏 |
| 手机（全部） | 右上角"菜单"按钮 → 从右侧滑出的抽屉，五个入口竖排大字 | 手机上横排塞不下 |

另外每页顶部都有一条**面包屑**（首页 / 逛陶器 / 青釉茶杯），保证客户永远知道自己在哪。

## 5. 施工顺序（每一步做什么、怎么验收）

> 我按这个顺序做，每完成一步你都能在浏览器里看到。**建议先做 Step 0–3，你看过首页再决定要不要调。**

### Step 0 · 地基（约 20 分钟）
- 建 `ceramic-web/`，Vite + Vue 3 + Router + Pinia
- 目录分好：`styles/`、`components/`、`views/`、`data/`、`stores/`、`api/`
- 搬素材：7 个 webm + `avatar.png` 进 `public/assets/agent/`
- **验收**：`npm run dev` 起得来，浏览器能打开

### Step 1 · 设计系统
- `tokens.css`：6 个颜色、字号阶梯、间距、12 列网格
- 基础组件：按钮、标签、极细分割线、章节编号、图片+摄影说明、输入框、弹窗、轻提示
- 纸张颗粒：一层极淡的噪点纹理（opacity 0.04）
- **验收**：打开 `/styleguide` 能看到所有颜色和组件

### Step 2 · 欢迎层
- 全屏奶油白，中间一个圆头（陶土色渐变），**眼睛跟着鼠标转**，会眨眼
- 头顶气泡轮播台词："你好，我是垚垚。""一起看看泥土怎么变成日常的陪伴。"
- 下方"进入陶的世界"按钮 + 右上角"跳过"
- 看过一次就记住，下次直接进首页；手机上点一下头会换个表情
- **验收**：鼠标移动眼睛跟手；点进入能进首页；刷新后不再出现

### Step 3 · 首页五章 + 覆盖式滚动
- 核心效果：往下滚，**下一章从下面滑上来盖住上一章**（`position: sticky` + 层级递增），回滚能看回去
- 01 封面：超大英文 `THE ART OF CLAY` 与中文"让泥土，成为陪伴"错位叠在大图上，两个入口
- 02 这一期：一大两小、高低错落，不是整齐的商品格子
- 03 从泥到器：大幅图 + 窄栏文字 + 工序编号
- 04 留下一道纹样：器型 / 纹样 / 成品 三张并置 + 入口
- 05 认识垚垚：克制的角色区 + 聊天入口
- 右侧章节条随滚动高亮
- **验收**：滚动顺滑不卡；系统开了"减少动态效果"时自动退化成普通滚动

### Step 4 · 商品链路
- 先造 8 件陶器的数据（名称/系列/价格/规格/库存/材质/尺寸/工艺/能否定做）
- 列表页（左筛选 + 稳定网格，悬停轻微放大）、详情页（左 60% 图 / 右 40% 购买区）
- 购物袋 → 结算 → 模拟支付 → 订单列表 → 订单详情
- 数据存浏览器本地，**刷新不丢**
- **验收**：加购→结算→支付→订单出现在"我的订单"

### Step 5 · 定做工作台 + 纹样库
- 纹样库：12–16 个纹样，带类别/来源/寓意/适用器型
- 定做：左四步（器型→纹样→颜色→位置），中间 SVG 实时预览（器型底图 + 蒙版 + 纹样层 + 高光层），右边配置和报价
- 存方案进"我的定做"，也能直接下单（订单里存一份配置快照）
- **验收**：换纹样/颜色/位置预览立刻变；保存后刷新还在

### Step 6 · 我的
- 概览 + 订单 + 收藏 + 定做 + 地址，五个子页
- **验收**：各页面数据对得上

### Step 7 · 垚垚接进来
- 右下角入口：复用 `pet-widget.js` 的播放机制，改成本站场景（首页/列表/详情/购物袋/支付成功/售罄）
- 点开是聊天面板：形象区 + 消息流 + 输入框
- 走真接口 `POST /api/chat`，读 SSE：`session / token / emotion / tool / done / error`
  - `token` → 逐字出字
  - `emotion` → 切 webm 动作（happy→双手比心，thinking→犹豫纠结，greeting→挥手欢迎…）
  - `tool` → 显示"正在算…"
- 后端没启动时：面板里给一句人话提示 + 本地兜底回答，不白屏
- **验收**：能真的聊起来；关掉后端有明确提示

### Step 8 · 收尾
- 三档响应式（≥1280 / 768–1279 / <768）、图片懒加载、动效降级、键盘可达、对比度
- 跑一遍完整流程自检，写 README（怎么启动、怎么换图、怎么换视频）
- **验收**：手机宽度下不出横向滚动条，按钮都点得到

## 7. 图片怎么办（需要你拍板）

现在一张商品图都没有。三个选择：

- **A（推荐）我画一套**：用 SVG 画陶器（器型轮廓 + 釉色渐变 + 颗粒噪点 + 柔和投影）和纹样，统一画风配色，4:5 和 3:2 两种画幅。好处是今天就能看到完整效果，以后换真照片只替换文件、不动代码。工艺/人物这类大图不硬凑，用米色块 + 细线框 + 摄影说明占位，明确标"待换真实摄影"。
- **B 全部留空框**：页面结构先做好，图片位置是标好尺寸的空框，你后面自己放。
- **C 你给真图**：你马上提供一批陶器照片，我按真图排版（效果最好，但要等图）。

## 8. 技术方案与怎么跑

```
ceramic-web/
├─ frontend/            Vue 3 + Vite + Router + Pinia
│  ├─ public/assets/    agent/(7 个 webm + avatar.png)、brand/、products/、patterns/
│  └─ src/              views / components / stores / data / api / styles
├─ agent/               垚垚后端（从 my-agent.zip 搬 src/，不改逻辑）
├─ docs/                本方案 + 素材清单 + 验收清单
└─ README.md            启动说明
```

- 前端：`npm run dev` → `http://127.0.0.1:5173`
- 后端：`uvicorn src.server:app --port 8000`，前端把 `/api` 代理过去
- 数据：商品/纹样/故事先放前端 JSON；订单、收藏、定做方案存浏览器本地
- **第一版不做**：真实支付、数据库、管理后台、3D 形象、宠物养成数值（成长值/装扮/奖励规则你还没定，先留位置）
